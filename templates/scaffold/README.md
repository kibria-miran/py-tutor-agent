# __PACKAGE__

A throwaway starter project created by the Python tutor.

This sandbox project is not kept by the tutor. Copy it somewhere else if
you want to continue working on it.

## Layout

- `src/__PACKAGE__/` - importable package code
- `tests/` - pytest tests
- `pyproject.toml` - packaging and tool configuration

## Run the tests

```bash
python -m pytest
```
